## どの方法を使うか

| 方法 | 手軽さ | 向いているもの |
|---|---|---|
| lilToon の **色調補正** | いちばん手軽。テクスチャを触らない | 髪・服の色を全体的に変える |
| 画像編集ソフトで **色相・彩度** を変える | 改変用 PSD があれば簡単 | 一部のパーツだけ色を変える |
| **グラデーションマップ** | 少し手間 | 元の明暗を保ったまま、まったく違う色にする |
| **半透明のレイヤー** を重ねる | 少し手間 | タイツ・ストッキング・日焼け |

最初は lilToon の色調補正を試し、思った色にならなければテクスチャを編集する、という順がおすすめです。どの方法でも、**元のマテリアルとテクスチャは複製してから** 触ると、いつでも元に戻せます。

## 1. lilToon の色調補正

テクスチャを描き直さずに、マテリアルの設定だけで色を変えます（[Q&A: 髪の色を変える](/qa#hair-color-change)）。

1. Project ウィンドウで、色を変えたいマテリアルを選んで <kbd>Ctrl</kbd>+<kbd>D</kbd> で複製する
2. 複製したマテリアルを、メッシュの Skinned Mesh Renderer の Materials に入れる（[マテリアルとシェーダー](/learn/unity/liltoon-basics)）
3. Inspector の **メインカラー / 透過設定** の **色調補正** を開き、**色相**・**彩度**・**明度**・**ガンマ** を動かす

- **色相** は、色相環を回すように色だけを変える。元の濃淡はそのまま残る
- 白っぽくしたいときは **彩度** を下げ、**明度** を上げる
- **色調補正マスク** を使うと、マスクの黒い部分には色調補正がかからない（髪のメッシュの中で、リボンだけ色を変えたくないときなど）
- **焼き込み** のボタンで、色調補正したあとの色をテクスチャとして書き出せる。VRM 用に MToon へ変換するときや、Android 用のシェーダーに変えるときは、焼き込んだテクスチャを使う

lilToon には、メインカラーの **グラデーションマップ** の機能もあります。下の「3. グラデーションマップ」と同じことを、マテリアルの設定だけでできます。

## 2. 画像編集ソフトで色相を変える

テクスチャそのものの色を変えます。使っているテクスチャの場所は [何て名前？: テクスチャの画像ファイルを探したい](/howto#find-texture) で探せます。

1. アバターや衣装に **改変用の PSD** が付いていれば、それを開く（無ければ PNG のテクスチャを開く）
2. 色を変えたいパーツのレイヤーを選び、色相・彩度の調整をする
   - GIMP: **色 > 色相-彩度**
   - CLIP STUDIO PAINT: **編集 > 色調補正 > 色相・彩度・明度**（色調補正レイヤーにすると、あとから変えられる）
3. PNG で書き出し、元のテクスチャと同じ名前で上書きするか、別名で保存してマテリアルに入れる

::: tip
PSD は Photoshop の形式で、GIMP などで開くとレイヤーが崩れることがあります。崩れるときは、作者が推奨しているソフトや CLIP STUDIO PAINT で開いてください（[TIPS](/tips#psd-compatibility)）。
:::

## 3. グラデーションマップ

グラデーションマップは、元のテクスチャの **明るさ** を、指定したグラデーションの色に置き換える機能です。元の色に引っ張られないので、金髪を黒髪にする、のような大きな色変えでも、陰影が自然に残ります（[TIPS: グラデーションマップ](/tips#gradient-map-recolor)）。

1. 色を変えたいレイヤーの上に、グラデーションマップの色調補正レイヤーを足す（CLIP STUDIO PAINT・Photoshop にある）
2. 暗いところの色と明るいところの色を、目的の色から選んでグラデーションにする
3. 微調整して書き出す

色ごとにレイヤーが分かれているテクスチャに向いています。1 枚の画像に髪も肌も描かれている場合は、先に範囲を選んでからかけます。

## 4. 半透明のレイヤーでタイツ・日焼けを描く

素肌のテクスチャの上に、色を塗ったレイヤーを重ねて不透明度を下げると、下の肌の陰影が透けた **タイツ** や **ストッキング** になります（[Q&A: 素肌テクスチャでタイツを表現する](/qa#tights-texture-from-psd)）。

1. 肌のテクスチャ（PSD）に新しいレイヤーを作る
2. タイツにする範囲を選んで塗りつぶす。真っ黒より、少し茶色寄りの色の方が自然
3. レイヤーの不透明度を 50% 前後にする
4. PSD に UV のレイヤー（ポリゴンの割り付け図）があれば、表示して、その線に沿って範囲を決める

**日焼け** も同じ考え方で、肌に半透明の色のレイヤーを重ね、日焼けあとを残したい部分を消します。レイヤーの合成モード（乗算・焼き込みなど）を変えて比べると、よい色が見つかります。

## 5. 首と顔の色を合わせる

首すげ替えや、別のアバターのパーツを使ったときに、首と顔の肌の色が違うことがあります（[Q&A: 首と体の色を合わせる](/qa#neck-color-match)）。

- まず顔と体のマテリアルの設定（シェーダーと色調補正）をそろえ、lilToon の色調補正でおおまかに合わせる
- 継ぎ目は、体のテクスチャの首まわりを、顔側の色から体の色へのグラデーションでなじませる
- テクスチャの色が合っていても、**影設定**・**リムライト設定**・**マットキャップ設定** が顔と体で違うと継ぎ目が目立つ。それぞれのマスクに、継ぎ目付近が黒いマスク画像を入れると、継ぎ目だけ影響を外せる

ワールドによって明るさが違って見えるときは、色ではなくライティングの問題です（[表示がおかしいときの対処](/learn/unity/display-issues)）。

## 6. 瞳を差し替える

瞳のテクスチャを売っているものを使うときは、元の顔（目）のテクスチャに、瞳の画像をレイヤーとして重ねて書き出します（[Q&A: 瞳のテクスチャを差し替える](/qa#eye-texture-replace)）。アバター対応の瞳なら位置はそのまま合います。汎用のものは、UV を表示して位置を合わせます。

## 7. 髪にツヤを出す

髪の「天使の輪」のようなツヤは、lilToon の **マットキャップ設定** に白黒のツヤの画像を入れると出せます。見る角度で変わるので、テクスチャに描いたツヤより自然に見えます。さらに、髪の流れに沿った筋の画像から **ノーマルマップ** を作って入れると、さらさらした質感になります（[何て名前？: 髪にツヤを出したい](/howto#hair-gloss)）。

## よくあるつまずき

- **色を変えたら、別のアバターの色まで変わった**: 同じマテリアルを共有しています。マテリアルを複製してから変えてください
- **テクスチャを上書きしたのに変わらない**: Unity に別名のファイルとして読み込まれています。マテリアルに入っている画像がどれかを確かめてください
- **色が全体的に白っぽい・光って見える**: リムライトや発光（エミッション）の影響です（[Q&A](/qa#rim-light-glow)）
