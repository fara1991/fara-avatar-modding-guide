## 症状から探す

| 症状 | 原因 | 節 |
|---|---|---|
| 全体または一部がピンク（マゼンタ） | シェーダーが入っていない | 1 |
| 真っ白・テクスチャが無い | マテリアルが割り当てられていない | 2 |
| 透けた服越しに、別の透けたものが消える | 半透明どうしの描画順 | 3 |
| 表からは透けるのに、裏からは透けない | 描画モード・面の向き | 4 |
| 輪郭線が太い・何かに包まれて見える | スケールが変わって輪郭線が太くなった | 5 |
| 服が白く光る | リムライト・発光 | 6 |
| ワールドによって顔と体の明るさが違う | ライトの基準（Anchor Override）・Bounds・明るさの下限 | 7 |
| 一部の面が透けて見えない | 面の表裏（法線）が裏返っている | 8 |

## 1. ピンクになる

マテリアルが使うシェーダーが、プロジェクトに入っていません（[TIPS: マテリアルがピンクになる](/tips#pink-material)）。

1. アバターや衣装の説明書で、必要なシェーダー（lilToon など）とバージョンを確かめる
2. VCC のパッケージか、配布元の unitypackage でシェーダーを入れる
3. 直らなければ、マテリアルの Inspector の **Shader** で選び直す。シェーダーのフォルダを右クリック > **Reimport** も試す

## 2. マテリアルが外れる（Blender から書き出した FBX）

Blender で書き出した FBX には、Unity で使えるマテリアルは入っていません。元のアバターや衣装に付いている Unity 用のマテリアルを割り当て直します（[Q&A](/qa#blender-fbx-materials-in-unity)）。

1. Project で FBX を選び、Inspector の **Materials** タブを開く
2. **Remapped Materials** の各スロットに、元のマテリアルをドラッグして **Apply**

Blender でマテリアルの名前を変えていなければ、同じ名前のスロットに入れるだけで元どおりになります。

## 3. 半透明どうしで消える（描画順）

半透明（lilToon の描画モードが **半透明**）のものは、メッシュごとの基準の位置で描く順番が決まります。そのため、見る角度によって前後が入れ替わり、片方が消えて見えることがあります（[Q&A: 透過メッシュ越しに別の透過メッシュが消える](/qa#transparent-render-queue)）。

- **カットアウトで済むならカットアウトにする**: 描画モードを **カットアウト** にすると、この問題は起きません。レースや髪の毛先のように「透けるか透けないか」だけの部分はカットアウトで十分です
- **Render Queue で順番を決める**: マテリアルの **Render Queue** の数値が小さいものから描かれます。内側に見えるもの（中の小物、まぶた）を小さく、外側（ローブ、眼鏡のレンズ）を大きくします（例: 内側 2500、外側 2510）
- 同じマテリアルを共有しているメッシュどうしで起きるときは、マテリアルを複製して別々の値にします

## 4. 裏から透けない

- lilToon で描画モードを **半透明** にし、**透過モード** を **2パス** にすると直ることがあります（[Q&A](/qa#transparent-backface)）
- **Cull Mode (描画面)** が **Back (前面のみ描画)** だと、裏側の面は描かれません。両面を見せたいなら **Off (両面を描画)** にします
- カットアウトで裏側だけおかしいときは、メッシュの面の向きが裏返っているか、テクスチャのアルファ（透明度）に問題があります

## 5. 輪郭線が太い

Blender を通して書き出したら、スケールが変わって輪郭線（アウトライン）の太さが相対的に変わることがあります（[Q&A](/qa#outline-thick-after-blender)）。

- lilToon の **輪郭線設定** の **マスクと太さ** で太さを小さくする（0 で消える）
- しっぽなどが「何かに包まれて見える」のも、太くなった輪郭線のことがある
- そもそもスケールが変わらないよう、Blender でトランスフォームを適用し、FBX 書き出しのスケール設定を見直す（[FBX に書き出す](/learn/avatar-clothing/export-fbx)）

## 6. 白く光る

服が白っぽく光って見えるのは、たいてい **リムライト** か **発光**（エミッション）の強さです（[Q&A](/qa#rim-light-glow)）。

- lilToon の **リムライト設定** の色を暗くする、または強さを下げる
- **発光設定** がオンになっていないか確かめる
- 一部だけ白いときは、そのパーツ（ファスナーなど）だけ別のマテリアルで、設定し忘れていることがある

## 7. ワールドによって明るさが違う

顔と体、体と服で明るさが違って見えるときは、メッシュごとにライトの基準がずれています（[Q&A: 首と体の明るさが違う](/qa#neck-body-brightness-mismatch)）。

### Anchor Override と Bounds をそろえる

Skinned Mesh Renderer の **Anchor Override**（ライトを計算する基準の位置）と **Bounds**（表示する範囲）が、メッシュごとに違うと、同じ場所でも明るさが変わります。

- Modular Avatar の **MA Mesh Settings** をアバターのルートに付け、Anchor Override と Bounds を **設定** にすると、アバターの中のメッシュにまとめて同じ値が入ります
- 衣装を Setup Outfit で着せると、衣装にも Mesh Settings が付き、アバターに合わせてくれます
- Bounds が小さすぎると、見る角度によってメッシュが消える（表示されなくなる）こともあります。アバター全体が入る大きさにします

### シェーダーの明るさの設定をそろえる

lilToon の **ライティング・明るさ設定** にある **明るさの下限**・**明るさの上限** が、顔と体で違うと、暗いワールドで明るさに差が出ます。別のアバターのマテリアルを組み合わせたときに起きやすいので、値をそろえます。

## 8. 一部の面が透けて見えない

Unity は、既定では面の **表側** しか描きません。Blender で面の表裏（法線）が裏返っていると、その面は外から見ると透明になります（[TIPS: 面が黒い・Unity で一部が透けて見えない](/tips#flipped-normals)）。Blender の編集モードで全選択し、**メッシュ > ノーマル > 面の向きを外側に揃える**（<kbd>Shift</kbd>+<kbd>N</kbd>）をして書き出し直します。

## まだおかしいとき

- 同じ症状が Build & Test の VRChat でも出るか確かめる。Unity の Scene ビューと VRChat ではライティングが違うので、最終的には VRChat で判断します
- シェーダーの細かい設定は、[lilToon のドキュメント](https://lilxyzw.github.io/lilToon/ja_JP/) を見てください
