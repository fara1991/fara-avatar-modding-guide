## 必要なもの

- Blender
- アバター用ベースモデル
- テクスチャ作成ソフト（GIMP、Photoshop など）
- VRChat SDK（アップロード用）

## 手順

1. File > Import > FBX からアバターファイルを選択
2. インポート設定でスケールとアーマチュアを確認
3. アバターが正常に表示されることを確認
4. 必要に応じてマテリアルを再設定

::: tip
- インポート時にスケールが 1.0 になっているか確認
- アーマチュアが含まれているか確認
:::

::: warning
- 著作権に注意してください
- VRChat の利用規約を確認してください
- ポリゴン数の制限に注意してください
:::
