## 手順

1. UV Editing ワークスペースに切り替え
2. 編集モードで全面を選択（<kbd>A</kbd> キー）
3. <kbd>U</kbd> キー > Unwrap で UV 展開
4. UV > Export UV Layout で UV マップを書き出し
5. 外部ソフトでテクスチャを作成

::: tip
- シームマーク（<kbd>Ctrl</kbd>+<kbd>E</kbd> > Mark Seam）で展開位置を調整
- UV 密度を均等に保つことでテクスチャ品質を向上
:::
