## 手順

1. File > Export > FBX で服をエクスポート
2. Unity プロジェクトにファイルをインポート
3. アバターディスクリプターで Outfit を設定
4. マテリアル設定を調整
5. アップロード前にテスト

::: tip
- エクスポート時にスケールとアーマチュア設定を確認
- VRChat の制限（ポリゴン数、マテリアル数）に注意
:::
