## 全体の流れ

非対応衣装を着せる作業は、次の順に進めます。途中で戻ることも多いので、区切りごとに別名で保存しておくと安心です。

1. 規約を確かめる
2. アバターと衣装を Blender に読み込む
3. スケールを適用する
4. 位置と大きさを合わせる
5. 関節（ボーン）の位置を合わせる
6. 頂点グループの名前をそろえる
7. アバターの体からウェイトを転送する
8. 関節を曲げて確かめ、手で直す
9. 貫通を直す
10. FBX に書き出して Unity で着せる

うまくいかないときは [服が動かない・凹む・突き抜けるときのチェックリスト](/learn/modding/outfit-checklist) を見てください。Blender の基本操作は [基本操作](/learn/basics/select)、ウェイトの基本は [ウェイトペイント](/learn/rigging/weight-paint) にあります。

::: tip
はじめての非対応衣装は、**体にぴったりしない、構造が単純な服**（パーカー、ゆったりしたワンピースなど）から選ぶと挫折しにくいです。タイツや水着のように体の線がそのまま出る服、ヒールのある靴は難しい部類です。
:::

## 1. 規約を確かめる

非対応衣装の着せ替えでは、衣装の **改変** と、アバターの体の **ウェイトを衣装に流用** する（転送する）ことになります。どちらも商品ごとの規約で可否が決まります。

- 衣装: 改変してよいか、対応アバター以外に着せてよいか
- アバター: 素体のデータ（ウェイトなど）を他のデータの改変に使ってよいか
- 書いていないことは「できない」と考えておくのが安全です（[TIPS: 利用規約を確認する](/tips#check-license-terms)）

作ったデータを人に渡すのは、相手も両方を持っていて、規約で認められている場合だけにします（[Q&A](/qa#fbx-export-outfit-only)）。

## 2. 読み込む

アバターと衣装の FBX は、unitypackage を Unity に読み込んだときに Assets に入るものを使うのが確実です（[TIPS: unitypackage 内の FBX を使う](/tips#unitypackage-fbx)）。

1. **ファイル > 新規 > 全般** で新しいファイルを作り、最初からある立方体などを消す
2. **ファイル > インポート > FBX (.fbx)** でアバターを読み込む
3. 同じようにして衣装を読み込む

読み込みの設定は、[アバターを Blender に読み込む](/learn/avatar-clothing/import-avatar) と同じにします。アーマチュアの **ボーン方向の自動整列**（Automatic Bone Orientation）は **オフ** のままにします。オンにすると見た目は整いますが、ボーンの向きが変わり、Unity に戻したときに向きがずれる原因になります。

読み込むとアバターと衣装の両方にアーマチュアがあります。この段階では **2 つのアーマチュアを統合しません**。別々にしておくと、あとで衣装だけを選んで書き出せます。

## 3. スケールを適用する

FBX を読み込んだ直後のアーマチュアには、回転 X が 90°、スケールが 0.01 のような値が入っていることがあります。アバター・衣装それぞれのアーマチュアとメッシュを選んで <kbd>Ctrl</kbd>+<kbd>A</kbd> > **全トランスフォーム** を適用し、サイドバー（<kbd>N</kbd>）で回転 0、スケール 1 になっていることを確かめます（[TIPS: スケールを適用していない](/tips#unapplied-scale)）。

## 4. 位置と大きさを合わせる

1. 衣装のアーマチュアを選び、オブジェクトモードで <kbd>G</kbd> と <kbd>S</kbd> で、アバターにだいたい重なるように動かす
2. 正面（<kbd>Numpad 1</kbd>）と横（<kbd>Numpad 3</kbd>）から見て、肩と腰の高さを合わせる
3. 合ったら、もう一度 <kbd>Ctrl</kbd>+<kbd>A</kbd> > **全トランスフォーム**

衣装のアーマチュアを動かせば、アーマチュアで変形している衣装のメッシュも一緒に動きます。

## 5. 関節の位置を合わせる

ここがいちばん大事な工程です。衣装の関節（肩・肘・手首・脚の付け根・膝）がアバターの関節とずれていると、曲げたときに変な位置で折れたり、膝で凹んだりします。

方法は 2 つあります。

### 方法 A: ポーズモードで合わせて、レストポーズとして適用する

衣装のボーンを動かして体に合わせ、その形を「元の形」として確定する方法です。衣装のウェイトをそのまま使えます。

1. 衣装のアーマチュアを選び、<kbd>Ctrl</kbd>+<kbd>Tab</kbd> でポーズモードに入る
2. 肩・肘・脚の付け根・膝のボーンを <kbd>G</kbd> / <kbd>R</kbd> / <kbd>S</kbd> で動かし、アバターの関節に合わせる。袖や裾の太さもボーンの拡縮で合わせられる
3. オブジェクトモードに戻り、衣装のメッシュの **アーマチュア モディファイアーを適用** する（メッシュが今の形で確定する）
4. 衣装のアーマチュアをポーズモードにし、**ポーズ > 適用 > レストポーズとして適用**（ボーンが今の位置で確定する）
5. 衣装のメッシュに **アーマチュア モディファイアーを付け直し**、オブジェクトに衣装のアーマチュアを指定する

詳しくは [何て名前？: レストポーズとして適用](/howto#apply-pose-as-rest) を見てください。

::: warning
衣装のメッシュに **シェイプキーがある** と、手順 3 のアーマチュア モディファイアーの適用ができません（[TIPS](/tips#shape-key-modifier)）。その場合は方法 B を使うか、シェイプキーを保ったまま適用できるアドオンを使います。
:::

### 方法 B: 編集モードでメッシュを合わせる

ボーンは動かさず、衣装のメッシュを編集モードで直接動かして体に合わせる方法です。あとで体からウェイトを転送するので、衣装の元のウェイトがずれても構いません。

- 腕の長さが違うときは、袖の頂点をまとめて選び、<kbd>S</kbd> で腕の向きに縮めて肩側に寄せる（[Q&A: 腕の長さが合わない](/qa#arm-length-mismatch)）
- 広い範囲をなめらかに動かすときは、プロポーショナル編集（<kbd>O</kbd>）を使う。ボタンなど形を変えたくない部分は先に <kbd>H</kbd> で隠しておく（[TIPS](/tips#hide-vertices-while-editing)）
- 体にぴったりした服（タイツ・ソックス）は、シュリンクラップ モディファイアーで体に沿わせる方法もある（[何て名前？: 服を体の表面に沿わせたい](/howto#fit-to-body)）

## 6. 頂点グループの名前をそろえる

ボーンと頂点グループは **名前** でつながります。衣装の頂点グループの名前を、アバターのボーン名に合わせます。

- 衣装のボーン名がアバターと同じなら、そのままで構いません
- 違う場合（`UpperLeg_L` と `Upper_leg.L` など）は、衣装のアーマチュアの **ボーン名** をアバターに合わせて変えます。ボーン名を変えると、頂点グループ名も一緒に変わります
- ボーン名の確認は、アーマチュアを選んでアウトライナーで開くか、ボーンを選んで <kbd>F2</kbd>

方法 B で体からウェイトを転送するなら、名前は転送のときに体と同じものが作られるので、衣装側の名前はそろえなくても動きます。ただし、衣装の揺れもの用のボーン（スカート・リボンなど）のウェイトは残しておきたいことが多いので、どのボーンを残すかを先に決めておきます。

## 7. ウェイトを転送する

アバターの体から衣装へウェイトをコピーします。手順は [ウェイトを体から転送する](/learn/avatar-clothing/weight-transfer) と同じです。

- **データ転送 モディファイアー**: 衣装に追加し、ソースに体を指定して **頂点データ > 頂点グループ**、マッピングを **最近接面の補間** にし、**データレイヤーを生成** を押す
- **ウェイトを転送**: 体 → 衣装の順に選び（衣装がアクティブ）、ウェイトペイントモードで **ウェイト > ウェイトを転送**。シェイプキーがあってもそのまま使える

転送の前に、アバターと衣装の両方で **ポーズが付いていない** ことを確かめます。ポーズモードで全選択して <kbd>Alt</kbd>+<kbd>G</kbd> / <kbd>Alt</kbd>+<kbd>R</kbd> / <kbd>Alt</kbd>+<kbd>S</kbd> を押しておきます。

転送が終わったら、衣装のアーマチュア モディファイアーの **オブジェクト** を **アバターのアーマチュア** に変えます。こうすると、アバターのボーンで衣装が動きます。スカートなど衣装にしかないボーンを残したいときは、そのボーンをアバターのアーマチュアに移す（アーマチュアを統合して、親を体のボーンにする）必要があります（[Q&A: 衣装ボーンをアバターに統合する](/qa#merge-outfit-bones-into-avatar)）。

## 8. 曲げて確かめ、手で直す

アバターのアーマチュアをポーズモードにして、腕を上げる・肘を曲げる・脚を上げる・しゃがむ、を試します。

- 衣装がついてこない・置いていかれる → [チェックリスト](/learn/modding/outfit-checklist)
- 関節で凹む・折れる → 境目のウェイトを [ウェイトペイント](/learn/rigging/weight-paint) でぼかす
- 確認したら、ポーズを <kbd>Alt</kbd>+<kbd>R</kbd> などで戻す

ウェイトの細かい確かめ方と直し方は [ウェイトを確かめて直す](/learn/rigging/weight-check) にまとめています。

## 9. 貫通を直す

肌が衣装を突き抜けるときの対策は、効果の大きい順に次のとおりです（[TIPS: 体が服を突き抜ける](/tips#clothes-clip-through)）。

1. 衣装で隠れる部分の体のメッシュを消す
2. 体を細くするシェイプキーを作り、Unity で値を入れる（[シェイプキーを改変に使う](/learn/rigging/shape-keys-modding)）
3. 衣装の突き抜ける場所を <kbd>Alt</kbd>+<kbd>S</kbd> で少し膨らませる
4. 体と衣装のウェイトをそろえる（転送し直す）

体を消す・細くするのは **アバター側** の改変なので、衣装ごとに別のアバターのデータを作るか、シェイプキーで切り替えられるようにしておくと後で困りません。

## 10. 書き出して Unity で着せる

1. 衣装のメッシュと、衣装のボーンを含むアーマチュアを選び、**ファイル > エクスポート > FBX (.fbx)** で書き出す。設定は [FBX に書き出す](/learn/avatar-clothing/export-fbx) と同じ
2. Unity で FBX を読み込み、Project から Hierarchy のアバターの子に入れる
3. 衣装を右クリック > **Modular Avatar > Setup Outfit**（[Unity で着せる](/learn/avatar-clothing/unity-setup)）
4. マテリアルを割り当て直す。Blender のマテリアルは Unity では使えないので、元の衣装の Unity 用マテリアルを使う（[Q&A](/qa#blender-fbx-materials-in-unity)）
5. **Build & Test** で、VRChat の中で動かして確かめる

アバターの体を消したり細くしたりした場合は、アバター本体の FBX も書き出し直し、Unity で元の FBX を上書きします。ドラッグで入れると別名のファイルになるので、エクスプローラーで同じ名前のファイルに上書きします（[TIPS](/tips#unitypackage-fbx)）。

## Unity だけで済むこともある

ボディラインの出ないゆったりした服や、少しのはみ出しなら、Unity だけで（位置と大きさの調整、体を細くするシェイプキー、Modular Avatar の設定で）済むこともあります。どちらにするかの目安は [TIPS: Unity だけで着せるか、Blender を使うか](/tips#blender-vs-unity-fitting) を見てください。
