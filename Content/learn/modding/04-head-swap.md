## 首すげ替えとは

**首すげ替え** は、アバター A の頭を、アバター B の体（首から下）につなぐ改変です。顔は A、体形や対応衣装は B、という組み合わせを作れます。

難しいのは次の 4 つです。

| 難しいところ | 起きること | この記事の節 |
|---|---|---|
| ボーンのつなぎ方 | 頭がついてこない、Unity で Humanoid のエラー | 2. ボーンをつなぐ |
| 首の継ぎ目の形 | 首の後ろなどに切れ目が見える | 3. 継ぎ目のメッシュ |
| 継ぎ目のウェイト | 首を傾けると切れ目が開く | 4. 継ぎ目のウェイト |
| 色と明るさ | 首と顔の色が違う、ワールドによって明るさが違う | 5. 色を合わせる、6. 明るさを合わせる |

::: warning
2 つのアバターのデータを組み合わせるので、**両方の規約** で改変・他アバターとの組み合わせが認められているか確認してください（[TIPS: 利用規約を確認する](/tips#check-license-terms)）。最近は首すげ替えを補助するツールや、首すげ替え用の素体データが配られていることもあります。使えるならそちらが楽です。
:::

## 1. 読み込んで、使う部分だけ残す

1. 新しい Blender ファイルに、頭を使うアバター（A）と体を使うアバター（B）の FBX を読み込む（設定は [アバターを Blender に読み込む](/learn/avatar-clothing/import-avatar) と同じ）
2. 両方のアーマチュアとメッシュに <kbd>Ctrl</kbd>+<kbd>A</kbd> > **全トランスフォーム** を適用する
3. A は頭（顔・髪・目など）、B は首から下を残す。頭と体が 1 つのメッシュになっている場合は、編集モードで不要な側を選んで消す（<kbd>L</kbd> でつながった部分を選ぶと速い）
4. A の頭を、B の首の位置に合わせて移動・拡縮する。頭の大きさを変えると印象が大きく変わるので、正面と横から見て慎重に合わせる

## 2. ボーンをつなぐ

頭のメッシュは A の `Head` ボーンなどで動いています。これを B のアーマチュアで動かすようにします。

方法はおおまかに 2 つあります。

- **B のアーマチュアに統一する**（基本）: 頭のメッシュのアーマチュア モディファイアーの **オブジェクト** を B のアーマチュアに変える。頭の頂点グループ名（`Head`、`Neck` など）が B のボーン名と同じなら、それだけで B のボーンで動く。目や髪の揺れもの用のボーンなど、B にないボーンを使っている場合は、A のアーマチュアからそのボーンを B に移す（アーマチュアを統合して、不要なボーンを消し、親を B の `Head` にする）
- **アーマチュアを統合して整理する**: 両方のアーマチュアを <kbd>Ctrl</kbd>+<kbd>J</kbd> で統合し（B をアクティブにする）、重複した体のボーンを消して、A の頭の補助ボーンの親を B の `Head` にする

どちらの場合も、**Neck と Head が親子でつながっている** ことを、ポーズモードで首と頭を回して確かめます。

::: tip
体側（B）のボーン名を変えると、B 用の対応衣装の頂点グループとの対応が崩れます。名前を合わせるときは、**頭側（A）を B に合わせる** ようにします（[Q&A: 服が動かない](/qa#clothes-not-following-bones)）。
:::

Unity に入れて Humanoid のエラーが出るときは、FBX の **Rig > Configure** で、Neck・Head・Chest などの割り当てが正しいかを確かめます（[Q&A](/qa#head-swap-unity-humanoid-error)）。

## 3. 継ぎ目のメッシュ

頭と体のメッシュは別々なので、首のどこかに継ぎ目ができます。

- **首を少し伸ばして頭側に差し込む**: 体側の首の先を少しだけ頭の内側に入れると、切れ目が見えにくくなります。このとき Basis を直接動かさず、**シェイプキーで作る** と、あとで戻せます（[Q&A: 首の継ぎ目](/qa#neck-seam-mesh)）
- **首の後ろは少しゆとりを持たせる**: ぴったり合わせると、頭を動かしたときに後ろで切れ目が開きます
- 首の形を大きく変えたいときは、ラティス モディファイアーでまとめて変形すると楽です

## 4. 継ぎ目のウェイト

継ぎ目の頂点のウェイトが、頭側と体側で違うと、首を傾けたときに継ぎ目が開きます。

1. 頭と体の両方で、継ぎ目の頂点のウェイト（`Neck` と `Head` の配分）を確かめる。サイドバー（<kbd>N</kbd>）の **アイテム > 頂点ウェイト** で数値を見られる
2. 両側で同じ値になるように、片方に合わせる（体側に合わせると、衣装との相性を崩しにくい）
3. ポーズモードで首と頭を回して（<kbd>Ctrl</kbd>+<kbd>Tab</kbd>）、継ぎ目が開かないか確かめる。終わったら <kbd>Alt</kbd>+<kbd>R</kbd> で戻す

体側の `Neck` に `Head` のウェイトが少し混ざっているアバターもあるので、思い込まずに数値で確かめてください。ウェイトの確かめ方は [ウェイトを確かめて直す](/learn/rigging/weight-check) にあります。

## 5. 色を合わせる

首と顔の肌の色が違うときは、テクスチャで合わせます（[Q&A: 首と体の色を合わせる](/qa#neck-color-match)）。

1. 顔のテクスチャから、継ぎ目付近の色をスポイトで取る
2. 体のテクスチャの首まわりを選択範囲にして、上（顔側）は顔の色、下は体の色になるようにグラデーションでなじませる
3. 体全体の色味が違うときは、先に lilToon の色調補正でおおまかに合わせる（[テクスチャの色を変える](/learn/unity/recolor)）

テクスチャの色が合っていても、MatCap・リムライト・影の設定が顔と体で違うと、継ぎ目が目立ちます。lilToon では、それぞれのマスクに「継ぎ目付近が黒い」マスク画像を入れると、継ぎ目だけ影響を外せます。

## 6. 明るさを合わせる

ワールドによって首（顔）と体の明るさが違って見えるときは、ライティングの基準がメッシュごとにずれています（[Q&A: 首と体の明るさ](/qa#neck-body-brightness-mismatch)）。

- **Anchor Override と Bounds をそろえる**: 顔・体・衣装のすべての Skinned Mesh Renderer で、ライトの基準（Anchor Override）と表示範囲（Bounds）をそろえます。Modular Avatar の **MA Mesh Settings** をアバターのルートに付けると、配下のメッシュにまとめて設定できます
- **シェーダーの設定をそろえる**: 顔と体で、lilToon の **明るさの下限** などのライティング設定が違うと、同じ場所でも明るさが変わります。別のアバターのマテリアルを使ったときによく起きます

詳しくは [表示がおかしいときの対処](/learn/unity/display-issues) を見てください。

## 7. 書き出して確かめる

1. 頭と体のメッシュ、B のアーマチュアを選んで FBX に書き出す（[FBX に書き出す](/learn/avatar-clothing/export-fbx)）
2. Unity で FBX の Rig を **Humanoid** にして **Configure** で割り当てを確かめる
3. B の Prefab を元に、FBX を差し替えるか、新しい Prefab を作る。VRC Avatar Descriptor の **View Position**（目の位置）、**Lip Sync**（口のシェイプキー）、**Eye Look**（目の動き・まばたき）を頭側のメッシュに合わせて設定し直す
4. 表情のアニメーションは「メッシュ名 / シェイプキー名」で参照しているので、顔のメッシュ名が変わったら合わせる（[Q&A](/qa#merged-mesh-expression-broken)）
5. Build & Test で、表情・首の動き・明るさを確かめる

着替えや首すげ替えのあとに PhysBone が動かなくなったときは [Q&A](/qa#physbone-lost-after-dressing) を見てください。
