リンク集

アバター改変の相談で紹介されたツール・資料・商品のリンクです。Blender のアドオンは アドオン のページにまとめています。

外部のサイトです。配布・販売の状況や対応バージョンは変わることがあるので、使う前・買う前にリンク先で確かめてください。古い情報 は、今は別の方法が主流になっている・販売や更新が終わっている可能性があるものです。

Unity のツール (17) VRChat (6) 参考になる記事・資料 (22) BOOTH: アバター (26) BOOTH: 衣装・小物 (34)

Unity のツール

Unity で使うエディタ拡張・アセット。導入は配布ページの案内（VCC / ALCOM、unitypackage など）に従ってください。

  • Modular Avatar 今も使われている Discord より
    衣装の Setup Outfit、メニュー・トグル、アニメーター統合などを非破壊で行う定番ツール
    現行の着せ替え・ギミック導入の標準的な手段。
  • Avatar Optimizer (AAO) 今も使われている Discord より
    アップロード時に非破壊でメッシュ結合・未使用要素削除などの軽量化を行う
    現行の軽量化の定番。MeshBaker の代替。
  • Continuous Avatar Uploader 今も使われている Discord より
    複数のアバターを連続で自動アップロードする
    2024 年時点で利用報告あり。
  • unity-overwriter Discord より
    Unity に同名ファイルをドラッグ＆ドロップしたとき上書きできるようにする（FBX 更新が楽になる）
    2023 年時点で利用。UPM（git URL）または Release の zip から導入。
  • CopyComponentsByRegex Discord より
    ボーン名を正規表現で対応付けてコンポーネント（揺れもの等）を一括コピーする
    PhysBone でも使えるかは確かめてください。MA で衣装を分離する運用なら不要な場面も多い。
  • UniVRMExtensions Discord より
    FBX から直接 VRM プレハブ化し、FBX を上書き更新しやすくする（VRMInitializer）などの VRM 拡張
    VRM 0.x 向け。現行 UniVRM での対応は確かめてください。
  • Very Animation 今も使われている Discord より
    Unity 上でアニメーション（AFK モーションなど）を作成・編集する有料アセット
    現行も販売。セール対象になることがある。
  • VRCAvatarEditor Discord より
    表情アニメーションの作成や FX のデフォルト表情変更を GUI で行うエディタ拡張（beta）
    当時（SDK3 初期）の定番。現行 SDK・Unity 2022 での動作は未確認。 当時は VRCAvatarEditor で表情アニメーションの作成や FX のデフォルト表情の差し替えを GUI で行っていました。現在の SDK・Unity での対応状況は配布ページで確認してください。
  • DietShaper Discord より
    体を細くするシェイプキー（激やせシェイプキー）を自動作成する無料ツール。貫通対策に
    Unity バージョン対応は配布ページで確認してください。
  • MeshSplitter Discord より
    マテリアル単位などでメッシュを分割する Unity 拡張
    利用報告は少ない。現行対応は確かめてください。
  • にゃんにゃんメッシュエディター (MeshModifyTool) Discord より
    Unity 上でメッシュの分離・削除・変形を行うエディタ拡張（Blender を使いたくない人向け）
    現行対応は配布ページで確認してください。
  • にゃんにゃんアバターペインター (TextureModifyTool) Discord より
    Unity 上でテクスチャにワンポイントを描き込める。立体上の位置が UV のどこかを確認するのにも便利
    現行対応は配布ページで確認してください。
  • Animation Viewer Discord より
    アニメーションクリップをプレビューしやすくするエディタ拡張
  • Radial Inventory System V3 古い情報 Discord より
    オブジェクトの出し入れアニメーションとメニューを自動生成する VRChat 向けツール（無料）
    当時の定番。現在は Modular Avatar の Object Toggle / Menu Item で代替可能。
  • VRCHierarchyHighlighter Discord より
    Hierarchy に色を付けて見やすくする
  • Enhanced Hierarchy 2.0 Discord より
    Hierarchy にコンポーネント等の情報を表示する
  • Av3Emulator 今も使われている Discord より
    Avatars 3.0（Expressions メニュー、FX など）の動作を Unity 上でエミュレートする
    現行も利用されている。Gesture Manager も同用途。
