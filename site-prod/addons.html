おすすめアドオン

Blender の機能を拡張する便利なアドオンを紹介します。Unity のツールや参考になる記事は リンク集 へ。

Node Wrangler
マテリアル
Extension

マテリアルノードの編集を速くする定番アドオン。画像テクスチャの一括読み込みやノードのプレビューができる

Blender 4.1 までは内蔵アドオンでした。4.2 以降は Extensions Platform からインストールします。

  • Ctrl+Shift+クリックでノードの出力を一時的にプレビュー
  • Ctrl+T で画像テクスチャにテクスチャ座標・マッピングを一括接続
  • Ctrl+Shift+T で PBR テクスチャ一式を一括読み込み
  • ノードの接続・切断のショートカット
価格: 無料公式サイト
LoopTools
モデリング
Extension

頂点を円形に整える、平らにならす、間隔をそろえるなど、形を整える道具の詰め合わせ

Blender 4.1 までは内蔵アドオンでした。4.2 以降は Extensions Platform からインストールします。編集モードの右クリックメニューか、サイドバーの「編集」タブに出ます。

  • Circle（選択した頂点を正円に並べる。袖口や襟の調整に）
  • Flatten（平らにならす）
  • Space（頂点の間隔を均等にする）
  • Relax（なめらかにする）
価格: 無料公式サイト
VRM Add-on for Blender
ゲーム開発
Extension

VRM 形式のインポート・エクスポートと、VRM 用のメタ情報や MToon マテリアルの編集ができる

Blender 4.2 以降に対応。VRM で配布されているアバターを Blender に読み込むときや、VRM で書き出すときに使います。VRChat 向けの FBX 書き出しには不要です。

  • VRM 0.x / 1.0 のインポート・エクスポート
  • MToon マテリアルの編集
  • VRM 用のボーン割り当て（Humanoid）の設定
  • 表情（Expression）の設定
価格: 無料公式サイト
Cats Blender Plugin（Unofficial）
ゲーム開発
最新版は Blender 5.0 以降

VRChat アバター向けの整理・最適化ツール。ボーンの統合、マテリアルの結合、表情（ビジーム）の自動作成など

本家（absolute-quantum）は開発が止まっています。有志が保守している Unofficial 版は、最新版が Blender 5.0 以降向けです。Blender 4.5 で使うときは、GitHub の Releases から 4.x 対応と書かれたバージョンを選んでください。インストールは「ディスクからインストール」で ZIP を選びます。

  • MMD / VRM / FBX などからの読み込みとボーン名の整理
  • 空のボーン・頂点グループの一括削除
  • マテリアルの結合（Material Combiner が必要）
  • ビジーム（口パク）とアイトラッキングの設定
価格: 無料公式サイト
Material Combiner
ゲーム開発
GitHub の master から ZIP

複数のマテリアルとテクスチャを 1 枚のアトラスにまとめて、マテリアル数を減らす

Releases ではなく master ブランチの ZIP を「ディスクからインストール」してください（Releases 版だと「No module named」エラーが出ることがあります）。Cats からも呼び出せます。VRChat のパフォーマンスランクでマテリアル数を抑えるのに有効です。

  • 複数のマテリアルを 1 つにまとめる
  • テクスチャを 1 枚のアトラスに結合
  • 単色マテリアルも画像に変換して結合
価格: 無料（寄付歓迎）公式サイト
Extra Mesh Objects
ユーティリティ
Extension

歯車・パイプ・数学的な形状など、標準では含まれていない様々なメッシュを追加

Blender 4.1 までは内蔵アドオン「Add Mesh：Extra Objects」でした。4.2 以降は Extensions Platform からインストールします。

  • 歯車・ボルトなどの機械部品
  • パイプ・ハニカムなどの構造物
  • 数学的形状（多面体、曲面）
  • 装飾オブジェクト
価格: 無料公式サイト
RestoreSymmetry
モデリング
Discord より

左右非対称になった頂点を左右対称に復元するアドオン

2.8〜3.0 での動作報告のみ。最新 Blender 向けの fork があるとの情報あり。4.5 での動作は未確認。

価格: 無料公式サイト
Hide Only Vertex (Lock Vertex)
モデリング
Discord より

選択した頂点だけを編集不可（固定）にする有料アドオン

対応バージョン未確認。標準のプロポーショナル編集「接続のみ」や H 非表示で代替可能。

価格: 有料公式サイト
ApplyModifier
モデリング
Discord より

シェイプキーのあるメッシュにモディファイアーを適用できるようにするアドオン

Blender 標準では今もシェイプキー付きメッシュへの適用は不可のため需要あり。4.5 対応はリポジトリで確認してください。

価格: 無料公式サイト

Better FBX Importer & Exporter
ユーティリティ
Discord より

高機能な FBX 入出力（Maya 製アバターのシェイプキー名の問題などを補正）の有料アドオン

現行も販売。書き出し設定によって法線が変わる事例があるので標準エクスポーターとの比較推奨。

アドオンのインストール方法（Blender 4.2 以降）

Extensions Platform に掲載されているもの（Node Wrangler など）

  1. Edit > Preferences を開く
  2. Get Extensions タブで名前を検索
  3. Install をクリック（自動で有効化される）

.zip で配布されているもの（GitHub や Gumroad から入手したアドオン）

  1. Edit > Preferences を開く
  2. Add-ons タブ右上の ∨ メニューから Install from Disk... を選択
  3. ダウンロードした .zip ファイルを選択
  4. 一覧でチェックを入れて有効化

Blender 4.1 以前は Add-ons タブの Install... ボタンから .zip を選びます。
