APL でポーズを設定する流れ

AvatarPoseLibrary（APL）の公式の README・wiki（Beginner-Tutorials・Unity-Manual）の手順を、6 つに分けたものです。
1
VCC にリポジトリを追加
Settings → Packages → Add Repository に URL を貼り、Add
2
プロジェクトに APL を追加
任意のプロジェクトの Manage Project から追加
3
アバターの子に空の GameObject
アバターを Hierarchy に置き、右クリック → Create Empty。アバターの直下にする
4
コンポーネントを付ける
Add Component → 「Avatar Pose Library」を選ぶ
5
カテゴリーとポーズを登録
右上の + でカテゴリー。ポーズは項目で設定（複数なら Drop Area に Animation Clip をまとめてドロップ）
6
アップロードして使う
VRChat のアクションメニューに、Library Name の名前で出る
ポーズの元になる Animation Clip は、別に用意します。APL でポーズを作って保存する方法は、公式の資料に書かれていません（公式に記載なし）。
