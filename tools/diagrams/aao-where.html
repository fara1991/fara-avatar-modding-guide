AAO のコンポーネントを付ける場所

公式ドキュメントの「追加する場所」の説明を、図にしたものです。
Trace And Optimize（自動）
アバター全体を調べるコンポーネントなので、アバターのルートに付けます。
アバターアバターのルート
コンポーネントAAO Trace And Optimize
種別は Avatar Global Component です。
Merge Skinned Mesh（手動）
新しい空の GameObject を作り、そこに付けます。
GameObject新しい空の GameObject
メッシュを指定していない SkinnedMeshRenderer を付けます。
コンポーネントAAO Merge Skinned Mesh
種別は Source Edit Skinned Mesh Component です。統合したいレンダラーを、一覧に入れます。
統合すると、個々のメッシュをアニメーションでオン・オフできなくなります。統合後の Anchor Override や Root Bone は、統合先の SkinnedMeshRenderer に、手動で設定します。
