ショートカット一覧

Blender でよく使うキーボードショートカットを機能別に整理しました。

すべて 一般 選択 視点 編集 モデリング UV リギング ペイント
ショートカット機能カテゴリ説明
Ctrl+N新規ファイル一般新しい Blender ファイルを作成
Ctrl+O開く一般ファイルを開く
Ctrl+S保存一般現在のファイルを保存
Ctrl+Shift+S名前を付けて保存一般別名で保存（バージョン違いを残すときにも）
Ctrl+Z元に戻す一般直前の操作を取り消し
Ctrl+Shift+Zやり直し一般取り消した操作をやり直し
F3メニュー検索一般機能名を入力して実行。メニューの場所を覚えていなくても使える
F2名前を変更一般アクティブなオブジェクトやボーンの名前を変更
F9最後の操作を調整一般直前の操作のパネル（画面左下と同じ内容）を開き直す
Shift+R最後の操作を繰り返し一般直前の操作をもう一度実行
Ctrl+Spaceエリアの最大化一般マウス下のエリアを画面いっぱいに表示（もう一度で戻る）
Ctrl+Tabモード切り替えパイ一般オブジェクト / 編集 / スカルプト / ウェイトペイントなどを切り替え
Ctrl+Alt+Q四分割表示一般上・前・右・ユーザー視点の 4 画面を切り替え
A全選択選択すべてのオブジェクト（編集モードでは全要素）を選択
Alt+A選択解除選択すべての選択を解除
Ctrl+I選択反転選択選択状態を反転
Bボックス選択選択ドラッグした矩形の範囲を選択
Cサークル選択選択円形のブラシでなぞって選択（ホイールで半径を変更）
Lリンク選択選択編集モードでマウス下のつながったメッシュをまとめて選択
Ctrl+Lリンク選択（選択から）選択選択中の要素につながったメッシュをすべて選択
Alt+クリックループ選択選択辺ループ / 面ループを一周選択
Ctrl+Numpad +選択を拡大選択選択範囲を隣の要素まで広げる
Ctrl+Numpad -選択を縮小選択選択範囲を内側に縮める
Numpad 1前からの視点視点正面（-Y 方向）から見る。Ctrl を足すと後ろから
Ctrl+Numpad 1後ろからの視点視点背面（+Y 方向）から見る
Numpad 3右からの視点視点右（+X 方向）から見る。Ctrl を足すと左から
Numpad 7上からの視点視点上（+Z 方向）から見る。Ctrl を足すと下から
Numpad 5透視 / 平行投影の切り替え視点遠近感のある透視投影と、正確な寸法が見える平行投影を切り替え
Numpad 0カメラ視点視点レンダリング用カメラから見る
Numpad .選択を表示視点選択したものが画面の中心に収まるように視点を移動
Home全体を表示視点すべてのオブジェクトが見えるように視点を移動
Shift+MMB視点の平行移動視点Shift を押しながらホイールボタンをドラッグ
Ctrl+MMBズーム視点Ctrl を押しながらホイールボタンをドラッグ（ホイール回転でも可）
Alt+Z透過表示視点メッシュを透かして裏側の頂点も選択できるようにする
Zシェーディングパイ視点ワイヤーフレーム / ソリッド / マテリアルプレビュー / レンダーを切り替え
Nサイドバー視点3D ビューポート右側のパネル（位置・回転・スケールなど）を開閉
Tツールバー視点3D ビューポート左側のツール一覧を開閉
G移動編集選択したものを移動。続けて X / Y / Z で軸を固定
R回転編集選択したものを回転。R をもう一度押すとトラックボール回転
Sスケール編集選択したものを拡大縮小
X削除編集選択したものを削除（編集モードでは削除 / 溶解のメニュー）
Shift+D複製編集複製して移動モードに入る（Esc でその場に置く）
Alt+Dリンク複製編集メッシュデータを共有した複製を作る（片方を編集すると両方変わる）
Shift+A追加編集メッシュ・アーマチュア・ライトなどを追加
Ctrl+A適用編集位置 / 回転 / スケールをメッシュに焼き込む（書き出し前に必須）
Ctrl+P親を設定編集選択したオブジェクトをアクティブオブジェクトの子にする
Alt+P親子関係を解除編集親子関係をクリア（トランスフォームを維持する選択肢あり）
Ctrl+J統合編集選択した複数のメッシュを 1 つのオブジェクトにまとめる
H隠す編集選択したものを非表示
Alt+H隠したものを表示編集非表示にしたものをすべて表示
Shift+H選択以外を隠す編集選択したもの以外を非表示
Mコレクションへ移動編集選択したオブジェクトを別のコレクションへ移動（編集モードではマージ）
Shift+Sスナップパイ編集3D カーソルと選択物をお互いの位置に移動
Oプロポーショナル編集編集周囲の頂点も一緒になだらかに動かす（ホイールで範囲を変更）
Tab編集モード切り替え編集オブジェクトモードと編集モードを切り替え
1頂点選択モードモデリング頂点を選択する
2辺選択モードモデリング辺を選択する
3面選択モードモデリング面を選択する
E押し出しモデリング選択した頂点 / 辺 / 面を押し出して新しい形を作る
I面を差し込むモデリング面の内側にひと回り小さい面を作る（I を 2 回で個別に）
Ctrl+Rループカットモデリングメッシュを一周する辺を追加（ホイールで本数を変更）
Ctrl+Bベベルモデリング辺を面取りして角を丸める（ホイールで分割数を変更）
Kナイフモデリングメッシュをなぞって切断。Enter で確定
F面を作成モデリング選択した頂点 / 辺から面（または辺）を張る
Ctrl+E辺メニューモデリングシームをマーク、辺の細分化などの辺に関する操作
Ctrl+F面メニューモデリング面の三角化、グリッドフィルなどの面に関する操作
Ctrl+V頂点メニューモデリング頂点のスムーズ、頂点グループへの割り当てなどの操作
Alt+M分割モデリング選択した部分を切り離して別のメッシュ要素にする（くっついたまま）
P分離モデリング選択した部分を別オブジェクトに分離
Alt+S収縮/膨張モデリング面の向きに沿って均等に太らせる / 細らせる（服を体から浮かせるときに）
Shift+N面の向きを外側に揃えるモデリング面の表裏をそろえる。裏返った面が黒く見えるときに
UUV マッピングメニューUV展開、スマート UV 投影などの UV 展開の方法を選ぶ
Alt+R回転をクリアリギングポーズモードでボーンの回転を元に戻す（Alt+G で位置、Alt+S でスケール）
F (ペイント)ブラシのサイズペイントウェイトペイントなどのペイント系モードで、ブラシの半径をドラッグで変更
Shift+F (ペイント)ブラシの強さペイントペイント系モードでブラシの強さをドラッグで変更
Ctrl+クリックボーンを選択（ウェイトペイント）ペイントアーマチュア → メッシュの順に選んでウェイトペイントに入ると、ボーンの Ctrl+クリックで頂点グループを切り替えられる
