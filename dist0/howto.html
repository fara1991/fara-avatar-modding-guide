あの操作、何て名前？

やりたいことから、操作の名前・メニューの場所（日本語 / 英語 UI）・キーを引けます。名前がわかれば、Blender では F3（メニュー検索）にそのまま入力して実行できます。

服を体の表面に沿わせたい

シュリンクラップ モディファイアー Shrinkwrap Modifier

メニュー
プロパティ > モディファイアー > 追加 > 変形 > シュリンクラップ
英語 UI
Add Modifier > Deform > Shrinkwrap

「オフセット」で体から少し浮かせる。頂点を均等に膨らませるだけなら編集モードの Alt+S（収縮/膨張。面の向きに沿って動かす）。

詳しく

ソックス・タイツなど体にぴったりした衣装を合わせる（シュリンクラップ）

衣装を足が隠れる程度に大きくしてからシュリンクラップモディファイアーで素体に貼り付け、オフセットで少し浮かせます。その後ボーン名を合わせ、素体からウェイトを転送し、貫通する部分を膨らませて仕上げます。

  1. 衣装をプロポーショナル編集や拡大で、足全体を覆えるサイズにざっくり合わせます。
  2. シュリンクラップ（Shrinkwrap） モディファイアーを追加し、ターゲットに素体（足）のメッシュを指定します。
  3. オフセット で少しだけ浮かせます（例: 0.0025 m 程度。アバターのスケールにより調整）。
  4. 端がガタガタになるので、手で整えるためにモディファイアーを適用します（LoopTools で縁を揃えると楽です）。
  5. 衣装のボーン（頂点グループ）名を素体に合わせ、Armature モディファイアーのオブジェクトを素体側に変更します。
  6. ポーズモードで素体を動かして貫通を確認し、ウェイト転送 をします。
  7. 残る貫通は、素体と衣装のポリゴン位置の差が原因です。貫通箇所を細分化する、衣装を少し膨らませるなどで対処します。
  • 関節付近（お腹、肩など）は IK で動いたときに貫通しやすいので、何往復か確認・微調整します。
  • シュリンクラップは楽ですが UV が歪みがちです。きれいに仕上げたい場合は事前にポリゴンが素体に沿って並ぶよう位置調整してからかけるか、プロポーショナル編集で地道に合わせます。
  • シュリンクラップには「ラップ方法」（最近接表面の点、ターゲットの法線で投影 など）と「スナップモード」（サーフェスの外側 など）があるので、仕上がりを比べて選びます。

体のウェイトを服にコピーしたい

データ転送 モディファイアー（頂点グループ） Data Transfer Modifier (Vertex Groups)

メニュー
プロパティ > モディファイアー > 追加 > 編集 > データ転送
英語 UI
Add Modifier > Edit > Data Transfer

「頂点データ > 頂点グループ」をオンにし、ソースに体を指定。先に「データレイヤーを生成」でボーンと同じ名前の頂点グループを作る。

詳しく

素体から衣装へウェイトを転送する

衣装の頂点グループ名を素体のボーン名に揃えたうえで、素体のウェイトを衣装へ転送します。データ転送モディファイアー（頂点データ → 頂点グループ、最近接面の補間）か、ウェイトペイントモードの「ウェイトを転送」を使います。

事前準備

  • 衣装の位置・大きさ・関節位置を素体に合わせておきます（ボーンの位置と、ウェイトの境目の位置が合っていないと、膝などで凹みや貫通が起きます）。
  • 衣装の頂点グループ（またはボーン）の名前を素体のボーン名に揃えます。ボーン名を変えると頂点グループ名も一緒に変わります。
  • ポーズモードで動かしたままになっていないか確認します（Alt+G/R/S でクリア）。
  • 規約で素体ウェイトの流用が許可されているか 確認します。

方法 A: データ転送モディファイアー

  1. 衣装メッシュに データ転送（Data Transfer） モディファイアーを追加します。
  2. ソースに素体のメッシュを指定し、頂点データ にチェック → 頂点グループ、マッピングは 最近接面の補間（Nearest Face Interpolated） を選びます。
  3. データレイヤーを生成 を押し、モディファイアーを適用します。シェイプキーがあると適用できません。
  4. 適用する前に確かめるときは、データ転送モディファイアーを Armature モディファイアーより上に置きます（下にあると、転送したウェイトが変形に使われません）。Armature モディファイアーは適用せずに残します。

方法 B: ウェイトペイントモードの転送（シェイプキーがあっても可）

  1. 素体 → 衣装の順に選択（衣装がアクティブ）し、ウェイトペイントモードにします。
  2. ウェイト > ウェイトを転送 を実行し、左下のパネルで 転送元レイヤーの選択 をすべてのレイヤー（All Layers）にし、頂点マッピング を 最近接面の補間 にします。既定ではアクティブな頂点グループ 1 つだけが転送されます。
  3. パネルで設定を変えたあとに頂点グループを選び直すと、やり直しになることがあります。おかしくなったら、もう一度 ウェイトを転送 を実行します。

仕上げ

  • 転送は完璧ではありません。関節や胸まわりなどは手でウェイトを塗って調整します（「転送してから塗る」が基本）。
  • 体の形が大きく違う服（胸を大きくした服など）を持ち上げると破綻する場合も、ウェイトの塗り直しが必要です。

衣装をアバターに着せたい

Setup Outfit（Modular Avatar） Modular Avatar > Setup Outfit

メニュー

英語 UI

衣装のアーマチュアに MA Merge Armature、衣装のルートに MA Outfit Root と MA Mesh Settings が付き、アップロード時に衣装のボーンがアバターのボーンへ統合される。衣装がそのアバターに対応しているか先に確かめる。

詳しく

対応衣装を着せる（現行: Modular Avatar の Setup Outfit）

対応衣装は、衣装の Prefab をアバターの子に置き、右クリックメニューの Modular Avatar「Setup Outfit」を実行するだけで着せられます。Blender での結合や手動のボーン入れ子は不要です。

  1. Modular Avatar（MA）を VCC / ALCOM でプロジェクトに追加します。
  2. アバターと衣装の unitypackage をインポートし、アバターの Prefab を Hierarchy に置きます。
  3. 衣装の Prefab（FBX ではなく）をアバターのルートの子にドラッグします。
  4. 衣装のルートを右クリック → Modular Avatar > Setup Outfit を実行します。衣装のボーンがアップロード時にアバターのボーンへ統合されます。
  5. 元の服を消す場合は、元の服メッシュを非アクティブにし、Tag を EditorOnly にします（非アクティブにしただけのものもアップロードに含まれます）。素体が衣装を突き抜ける場合は、作者が用意したシェイプキー（体を細くする等）を設定します。
  • 衣装の切り替えをメニューから行いたい場合は 衣装・小物の ON/OFF を参照してください。
  • 当時の方法: Blender でアバターと衣装のアーマチュアを結合してボーンを統合する方法（Blender で対応衣装を着せる）や、Unity 上で衣装ボーンを素体ボーンの子に入れる方法、Auto Dresser などのツールが使われていました。

揺らさない髪のボーンを減らしたい

親ボーンの頂点グループにウェイト 1.0 で割り当て → 子ボーンを削除

メニュー
編集モード > オブジェクトデータプロパティ > 頂点グループ > 割り当て
英語 UI
Object Data Properties > Vertex Groups > Assign

揺らさない髪などは、メッシュの全頂点を親ボーン（Head など）にウェイト 1.0 で割り当てれば、配下のボーンを削除できる。Humanoid に使われるボーンは消してはいけない。

詳しく
  1. Blender で髪のメッシュを選択し、編集モードで対象の頂点をすべて選択します。
  2. オブジェクトデータプロパティ（緑の▽）の頂点グループで、髪のルート（または Head）を選び、ウェイト 1.0 で 割り当て ます。
  3. 不要になった髪ボーンの頂点グループとボーンを削除します。
  • メッシュ結合済みでも、頂点グループごとに 選択 → まとめたいグループに 割り当て を繰り返せば同じことができます。
  • 消してよいボーン: Humanoid に含まれない補助ボーン（髪のルートより下、裾、スカートなど）。
  • 消してはいけないボーン: Hips、Spine、Chest、Head、手足など Humanoid に割り当てられているボーン。
  • スカートなどの補助ボーンを消す場合は、そのウェイトを Hips などにまとめます。
  • Chest 直下のアクセサリー用ボーンなどは、揺らさないなら Chest にウェイトをまとめても問題ありません。
  • 作業前にバックアップを取りましょう。

ポリゴン数を減らしたい

デシメート モディファイアー Decimate

メニュー
プロパティ > モディファイアー > 追加 > 生成 > デシメート
英語 UI
Properties > Modifiers > Add Modifier > Generate > Decimate

Blender のデシメート（Decimate）モディファイアーで比率を下げて適用する。頂点を手で削除・溶解するとシェイプキーや UV が壊れやすいので避ける。

詳しく
  1. 対象メッシュに デシメート（Decimate） モディファイアーを追加し、比率（Ratio）を下げて見た目を確認します。
  2. 問題なければ適用します。メッシュ構造は汚くなりますが、揺れたときの見た目の差は意外と小さいです。
  • シェイプキーがあるメッシュ はモディファイアーを通常の方法では適用できません（シェイプキーとモディファイアー）。当時は CATS の Decimation（シェイプキー保持）を使う方法がありました。
  • シェイプキー設定後に頂点数を変える（頂点削除・溶解）とメッシュが爆発する ことがあります。溶解は残った頂点で面を張り直すので形も崩れます。
  • 表示されない部分の頂点を削除しすぎると、別の角度から中身が透けて見えることがあります。削除前に保存・バックアップを取りましょう。

衣装や小物をメニューで ON / OFF したい

Create Toggle（Modular Avatar の MA Object Toggle） Modular Avatar > Create Toggle

メニュー
Hierarchy でアバターを右クリック > Modular Avatar > Create Toggle
英語 UI
Right-click avatar > Modular Avatar > Create Toggle

アバターを右クリックして Modular Avatar > Create Toggle を選ぶと、MA Menu Installer・MA Menu Item・MA Object Toggle の付いたオブジェクトが作られる。Object Toggle の + で切り替えたいオブジェクトを入れるだけで、アニメーションやパラメーターを手書きせずに Expression メニューから表示を切り替えられる。

詳しく

現行（Modular Avatar）

  1. Hierarchy でアバター（ルート）を右クリックし、Modular Avatar > Create Toggle を選びます。アバターの中に、MA Menu Installer・MA Menu Item・MA Object Toggle の付いたオブジェクトが作られます。オブジェクトの名前がメニューの項目名になります。
  2. MA Object Toggle の + で、切り替えたいオブジェクト（上着、帽子など）を入れます。チェックが付いていると「メニューを ON にしたら表示」、外すと「メニューを ON にしたら隠す」になります。
  3. MA Menu Item で、初期状態（初期設定にする / Is Default）、保存（保存する / Saved）、同期（同期する / Synced）を設定します。
  • 複数のオブジェクトを選んで Modular Avatar > Create Toggle for Selection を使うと、選んだものごとのトグルをまとめて作れます。
  • 手で組む場合は、空のオブジェクトに MA Menu Installer と MA Menu Item を付け、同じオブジェクトに MA Object Toggle（Add Component > Modular Avatar > MA Object Toggle）を付けます。
  • 衣装のズボンとスカートのように両方入っている衣装は、使わない方を非アクティブにするか削除し、両方使うならトグルで切り替えます。

当時の方法

  • VRChat SDK3 では「パラメーター」「アニメーション」「Expressions メニュー」をそれぞれ手で作る必要があり、Radial Inventory System などの自動化ツールが使われていました。
  • メニューに追加したのに反映されない場合は、FX レイヤー・パラメーター・アニメーションの対応や Write Defaults を確認します。
  • Beat Saber / VMC など VRM 系では MaterialChange 系 MOD に対応したアニメーションを用意します。

ポーズモードで合わせた形を、そのまま元の形にしたい

レストポーズとして適用 Apply Pose as Rest Pose Ctrl+A

メニュー
ポーズモード > ポーズ > 適用 > レストポーズとして適用
英語 UI
Pose > Apply > Apply Pose as Rest Pose

衣装の元のウェイトを活かすには、衣装のボーンをポーズモードでアバターの関節位置に合わせる。そのあと、Armature モディファイアーの適用 →「レストポーズとして適用」→ Armature モディファイアーの付け直し、という手順で形を確定させる。

詳しく
  1. 衣装をアバターに重ね、全体をスケールしておおよそのサイズに合わせます。
  2. 衣装のアーマチュアをポーズモードにし、肩・肘・膝などの関節位置をアバターに合わせます（袖の太さなども拡縮で調整可能）。
  3. オブジェクトモードに戻り、衣装メッシュの Armature モディファイアーを適用 します（メッシュが変形後の形で確定します）。
  4. 再びポーズモードに入り、ポーズ > 適用 > レストポーズとして適用 を実行します（ボーンが変形後の位置で確定します）。
  5. 衣装メッシュに Armature モディファイアーを付け直し ます（適用するとボーンとのつながりが消えるため）。
  6. 体を貫通する部分は、メッシュを直接編集して調整します。
  • シェイプキーがあると手順 3 の適用ができません（シェイプキーとモディファイアー）。
  • 部位によってメッシュの伸び縮みが変わるため、大きくずらすとテクスチャに違和感が出ることがあります。
  • 当時は CATS プラグインの「ポーズをレストポーズとして適用」でこの工程をボタン 1 つで行えましたが、CATS 本家は更新が止まっており、Blender 2.9 以降でシェイプキーが壊れる報告もありました。現行の Blender 4.5 では手動手順か、現行版に対応した後継ツールを使ってください。

ウェイトの合計を 1 にそろえたい・一部のウェイトを消したい

すべてを正規化 Normalize All

メニュー
ウェイトペイントモード > ウェイト > すべてを正規化
英語 UI
Weight Paint > Weights > Normalize All

ウェイトを 0 にしてよいなら、編集モードで対象頂点を選んで「ウェイト 0 で割り当て」。他グループとの合計を 1 にしたいならウェイトペイントの「すべてを正規化」。グループ同士で引き算したいなら頂点ウェイト合成モディファイアーを使う。

詳しく
  • ウェイトを 0 にする: 編集モードで、消したい範囲の頂点を選択（別グループの 選択 ボタンで選ぶと便利）→ ウェイトを消したい頂点グループをアクティブにし、ウェイト値 0 で 割り当て。グラデーションを残したい場合は手で塗るしかありません。
  • 正規化: ウェイトペイントモードで ウェイト > すべてを正規化。1 頂点に 3 つ以上の頂点グループが関わる場合は、それらすべてに影響する点に注意します。元の服のウェイトが正規化されていないまま転送すると、意図しない影響が出ることがあります。
  • グループ A から B の分を差し引く: 頂点ウェイト合成（Vertex Weight Mix） モディファイアーで、頂点グループ A に A、頂点グループ B に B を指定し、ミックスモード を 減算 にして、対象にする頂点（頂点セット）を選んでから適用します。

髪にツヤ（天使の輪）を出したい

MatCap ＋ ノーマルマップ（lilToon）

MatCap に天使の輪のような白黒の模様を入れると、見る角度で変化するツヤが出る。それだけだと金属っぽくなるので、髪の流れに沿ったヘアライン画像からノーマルマップを作って割り当てると、さらさらした質感になる。

詳しく

1. MatCap でツヤを出す

  • マテリアルの MatCap（lilToon では「マットキャップ設定」）に、天使の輪のような白黒の模様の画像を設定します。見る角度で変化するため、リアルなツヤ感が出ます。

2. ヘアラインのノーマルマップで毛並み感を出す

  1. ライセンス上問題のないヘアライン（髪の筋）画像を用意するか、自分で描きます。髪テクスチャの向きが一方向でない場合は、テクスチャの毛の流れに合わせて筋の向きを描き分けます。
  2. 白黒の画像からノーマルマップを作ります。
    • Unity だけで作る: 画像の Import 設定で Texture Type を Normal map にし、Create From Grayscale にチェック、凹凸の強さ（Bumpiness）を小さめ（例: 0.02 前後）にして Apply。
    • GIMP で作る: ノーマルマップ生成プラグインを入れて変換します。
  3. 髪マテリアルのノーマルマップ欄（lilToon では「ノーマルマップ設定」）に設定し、強さ（ノーマルマップ強度）を 0.05〜0.5 程度で調整します。
  • 手軽な方法として、髪のメインテクスチャを複製して上記の方法でノーマルマップにするやり方もあります（平坦なテクスチャではうまくいきません）。
  • ノーマルマップはテクスチャが 1 枚増えるので、その分データ容量が増えます。
  • 本来はスカルプトで凹凸を作って転写するものですが、描いた画像からでも十分効果があります。
